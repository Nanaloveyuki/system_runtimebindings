# Staged Platform Delivery

Status: accepted

Deliver Android first, and begin HarmonyOS API evaluation only after the Android MVP's capability contract, adapter, and verification path are stable. The project remains one cross-platform capability layer, not two independent submissions; staging avoids making MoonOHOS APIs, HarmonyOS device access, and any shim prerequisites for the first usable Android release. Future HarmonyOS scope is conditional on published upstream interfaces and a concrete matching capability. Cross-platform modules and conformance abstractions are introduced only when multiple real adapters establish shared semantics, rather than being required in the Android MVP.

The current Android increment adds `device_info.sdk_level()` through AJNI's checked static-field access and consumes it from Orbit Memo's Android `memo.runtime` command. It reads `Build.VERSION.SDK_INT`, owns and releases its temporary class handle, and needs no Context or new JNI primitive. Desktop responses may omit the Android-only `sdkLevel`; a supplied value must be a positive integer.

Stage 3 starts only after the capability passes native/JS checks, unsupported-target behavior, and a device IPC round trip comparing the returned value with Android's `Build.VERSION.SDK_INT`. Packaged assets remain a later increment: AJNI's Context API is available, but general blocking reads still need an off-main execution/completion contract. HarmonyOS implementation waits for stable Android capability contracts, consumer verification, and releasable upstream dependencies. AJNI 0.3.6 and BitLogger 0.11.1 provide the required published APIs.

After migration to published AJNI 0.3.6 and BitLogger 0.11.1, native/JS strict checks and unsupported-target tests passed. Android logging passed two install/launch/logcat runs, and Orbit Memo's API 37 x86_64 instrumentation passed. The test exercises the mounted React WebView and compares the IPC value with Kotlin's platform value. These results cover that runtime only; the local BitLogger publication blocker is resolved.
